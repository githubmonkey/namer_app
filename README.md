# Namer App

This repository contains the step-by-step implementation of the official Flutter codelab:
**[Your first Flutter app](https://codelabs.developers.google.com/codelabs/flutter-codelab-first)**.

It is organized into Git tags and worktrees corresponding to key milestones (checkpoints) throughout the codelab.

---

## Checkpoints Overview

| Tag | Worktree Directory | Codelab Steps | Description |
| :--- | :--- | :--- | :--- |
| `checkpoint_0` | `namer_app_0` | Step 1 & 2 | Initial default Flutter project generated by `flutter create`. |
| `checkpoint_1` | `namer_app_1` | Step 3: *Create a project* | Starter scaffold adding `english_words` and `provider` dependencies, configured `analysis_options.yaml`, and basic `MyAppState` generating random word pairs. |
| `checkpoint_2` | `namer_app_2` | Step 4 & 5: *Add a button* & *Make the app prettier* | Adds the `Next` button (`appState.getNext()`), centered layout, and extracts the `BigCard` widget styled with app theme colors (`primary` / `onPrimary`), 20px padding, custom typography, and screen-reader accessibility labels (`semanticsLabel`). |
| `checkpoint_3` | `namer_app_3` | Step 6, 7 & 8: *Add functionality*, *Add navigation rail* & *Add a new page* | Complete final app: adds favorites management with a `Like` button, responsive `NavigationRail` using `LayoutBuilder` (`extended` on screens >= 600px wide), and a scrollable `FavoritesPage` screen with `ListTile` items. |

---

## Working with Checkpoints

You can inspect or run each checkpoint side-by-side using the parallel worktrees located under `devfest_pretoria`:

```bash
# Check out any checkpoint tag directly
git checkout checkpoint_1

# Or list all active worktrees
git worktree list
```

In any worktree folder, install dependencies before running:

```bash
flutter pub get
flutter run
```
