# Namer App

This repository contains the step-by-step implementation of the official Flutter codelab:
**[Your first Flutter app](https://codelabs.developers.google.com/codelabs/flutter-codelab-first)**.

It is organized into Git tags corresponding to key milestones throughout the codelab.

---

## Checkpoints Overview

| Tag | Codelab Steps | Description |
| :--- | :--- | :--- |
| `checkpoint_0` | Step 1 & 2 | Initial default Flutter project generated by `flutter create`. |
| `checkpoint_1` | Step 3: *Create a project* | Starter scaffold adding `english_words` and `provider` dependencies, configured `analysis_options.yaml`, and basic `MyAppState` generating random word pairs. |
| `checkpoint_1b` | Step 4: *Add a button* | Adds the `Next` button (`appState.getNext()`) to generate a new random word pair. |
| `checkpoint_2` | Step 5: *Make the app prettier* | Centers the layout and extracts the `BigCard` widget styled with app theme colors (`primary` / `onPrimary`), 20px padding, custom typography, and screen-reader accessibility labels (`semanticsLabel`). |
| `checkpoint_3` | Step 6, 7 & 8: *Add functionality*, *Add navigation rail* & *Add a new page* | Complete final app: adds favorites management with a `Like` button, responsive `NavigationRail` using `LayoutBuilder` (`extended` on screens >= 600px wide), and a scrollable `FavoritesPage` screen with `ListTile` items. |

---

## Running a Checkpoint

You can check out any milestone using its tag:

```bash
git checkout checkpoint_1
flutter pub get
flutter run
```
